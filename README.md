# Faxo AI para Android

Tarjeta de sellos digital para negocios locales: el cliente junta sellos o puntos y el negocio los suma desde la caja con el celular.

## Instalar

1. En tu celular Android, abre este enlace: **https://github.com/neufsoft9/faxo-ai-descargas/releases/latest/download/faxo-ai.apk**
2. Cuando termine la descarga, toca el archivo. Android te pedirá permiso para instalar aplicaciones desde el navegador: acéptalo solo para esta instalación.
3. Abre **Faxo AI**. Puedes verla con datos de ejemplo sin crear cuenta ("Ver la app con datos de ejemplo").

Es una versión de revisión (0.1.0), anterior a la publicación en Google Play. Funciona en celulares Android de 64 bits (casi todos los de 2018 en adelante).

## Qué trae

- Para el negocio: crear el negocio, caja con escáner (sellos o puntos, también sin conexión), premios, carta QR, cajeros, cartel imprimible con QR y plan.
- Para el cliente: registro por QR, tarjeta con sus sellos y premios, y lista de sus tarjetas.

Más información: https://faxoai.com
